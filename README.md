# 原神解帧工具

**适配原神 7.2**

解除原神 PC 端的 60 帧限制，默认 120 fps。

## 使用方法

1. 首次使用前，先从**官方启动器**启动一次原神并进入游戏主界面，让工具记住游戏位置。
2. 双击 `Genshin-FPS-Unlock.exe`，在权限提示中点“是”。
3. 游戏自动启动并解帧。进入游戏后窗口会自动关闭，程序留在托盘继续生效。

之后直接双击即可，不需要再经过官方启动器。游戏已经在运行时双击，会立即对当前游戏生效。

关闭游戏后程序自动退出；也可以随时右键托盘图标选择“退出”。

## 修改帧率

用记事本打开同目录的 `config.ini`：

```ini
exe_path=Genshin Impact\Genshin Impact Game\YuanShen.exe
fps=120
```

把 `fps` 改成想要的数值（如 `120`），保存后重新双击程序。

`exe_path` 由程序自动填写，一般不用动。命令行运行 `--help` 可查看完整说明。

## 常见问题

**为什么需要管理员权限？**
原神本身以管理员权限运行，调整它的设置也需要同样的权限。点“是”即可。

**杀毒软件报警？**
工具需要读写游戏进程，可能被误报，添加信任即可。

**帧率没有变化？**
确认游戏内垂直同步已关闭，且显示器刷新率不低于目标帧率。

**提示“游戏路径已失效”或“当前游戏版本不受支持”？**
游戏位置变了或游戏刚更新，需要重新识别路径 / 使用新版工具。
